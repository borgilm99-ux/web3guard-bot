# 🛡 Web3Guard

> An open-source, community-driven tool and Telegram/Discord bot designed to detect phishing links, honeypot tokens, and malicious smart contracts.

## 🚀 Features (Under Active Development)
- **Token Contract Analyzer:** Real-time check for honeypots, mint backdoors, and liquidity locks.
- **Phishing URL Scanner:** Cross-checks domains against community-verified scam databases.
- **Free Telegram Bot:** Fast and accessible security lookup for Web3 users.

## 🤝 Support & Funding
Web3Guard is a **Public Goods** project. We believe in keeping open-source security accessible and free for everyone.
